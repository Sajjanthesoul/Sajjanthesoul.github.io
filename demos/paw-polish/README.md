# Paw & Polish — Pet Grooming & E-commerce Concept

A responsive concept storefront for an Indian pet grooming brand, built as a portfolio demonstration.

**Live demo:** https://sajjanthesoul.github.io/demos/paw-polish/

## Included
- Editorial-style responsive homepage and service sections
- Product catalogue with category filters
- Interactive shopping cart with quantity controls and INR pricing
- Booking request form demonstration
- GSAP entrance animation and scroll reveal effects
- Mobile-friendly layout and accessible labels

## Important
This is a front-end portfolio concept, not a production store. Checkout and booking are demonstrative only. A real launch requires the client's brand assets, product data, location/service details, payment gateway, shipping configuration, booking backend, privacy/terms pages, and domain setup.

## Stack
HTML, CSS, JavaScript, GSAP, Google Fonts, GitHub Pages.
